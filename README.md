# Adventure Works Sales Analysis Dashboard | Power BI

## 📊 Project Overview

This project presents an interactive **Adventure Works Sales Analysis Dashboard** built using **Microsoft Power BI**.

The objective was to transform raw sales and dimension data into meaningful business insights through data cleaning, data modeling, DAX calculations, KPIs, and interactive visualizations.

## 🛠️ Tools & Technologies

* Microsoft Power BI
* Power Query
* DAX
* Data Modeling
* Excel / CSV Data

## 🔄 Data Preparation

The project involved:

* Appending `FactInternetSales` and `FactInternetSalesNew`
* Merging Product, Product Subcategory, and Product Category data
* Creating relationships between Sales and dimension tables
* Building a star-schema style data model

## 🧮 Calculations & DAX

The project includes calculations for:

* Product Name lookup
* Customer Full Name
* Unit Price
* Order Date
* Year
* Month Number
* Month Name
* Quarter
* Year-Month
* Weekday Number
* Weekday Name
* Financial Month
* Financial Quarter
* Sales Amount
* Production Cost
* Profit
* Profit Margin

## 📈 Analysis & Visualizations

The project contains:

* Monthwise Sales Analysis
* Yearwise Sales Analysis
* Quarterwise Sales Analysis
* Sales vs Production Cost
* Top 10 Products by Sales
* Top 10 Customers by Sales
* Regional Sales Performance
* KPI Cards
* Interactive Year, Region, and Product Category filters

## 📌 Key KPIs

The dashboard includes:

* Total Sales
* Total Profit
* Total Orders
* Profit Margin %

## 🎯 Final Dashboard

The final dashboard provides an interactive overview of sales performance across products, customers, time periods, and regions.
